# COVID-19 Data Analysis

## Problem

### Description

The COVID-19 pandemic had a significant global impact, affecting public health systems, economies, and communities worldwide. Analyzing pandemic data helps understand the spread of the virus, monitor infection and recovery trends, and identify differences in its impact across countries and regions.

The objective is to explore COVID-19 cases, deaths, recoveries, and active cases over time and analyze how the pandemic evolved across different countries and WHO regions.

### Solution

Perform Exploratory Data Analysis (EDA) using the COVID-19 `full_grouped` dataset to investigate global pandemic trends and patterns.

The solution involves:

- Data cleaning and preprocessing.
- Exploratory data analysis and statistical analysis.
- Analyzing confirmed cases, deaths, recoveries, and active cases.
- Tracking daily changes in new cases, deaths, and recoveries.
- Comparing pandemic trends across countries and WHO regions.
- Identifying countries with the highest infection, death, and recovery counts.
- Visualizing geographical and temporal patterns using charts and graphs.

The goal is to extract meaningful insights into the global spread of COVID-19 and understand how its impact varied across countries and regions.

## Insights

### Features

The dataset contains 10 features describing COVID-19 statistics over time:

- **Date:** Date of the reported statistics.
- **Country/Region:** Country or region where cases were reported.
- **Confirmed:** Total confirmed COVID-19 cases.
- **Deaths:** Total reported deaths.
- **Recovered:** Total recovered cases.
- **Active:** Number of currently active cases.
- **New Cases:** Newly confirmed cases during the reporting period.
- **New Deaths:** Newly reported deaths during the reporting period.
- **New Recovered:** Newly reported recovered cases during the reporting period.
- **WHO Region:** World Health Organization region associated with each country.

### Target

No target variable — this project focuses on Exploratory Data Analysis (EDA) and statistical insights rather than supervised Machine Learning prediction.
