# House Rent Data Analysis

## Problem

### Description

Rental prices vary depending on several factors, including property size, number of bedrooms and bathrooms, location, furnishing status, and floor level. Understanding these factors helps tenants make informed rental decisions and helps property owners evaluate competitive rental prices.

The objective is to explore house rental data and investigate the factors influencing rent prices across different cities and property types.

### Solution

Perform Exploratory Data Analysis (EDA) using the House Rent dataset to understand rental price distributions and identify relationships between property characteristics and rent.

The solution involves:

- Data cleaning and preprocessing.
- Handling missing values and inconsistent data.
- Exploratory data analysis and statistical analysis.
- Analyzing rent distributions across different cities.
- Investigating the relationship between rent, property size, and BHK.
- Comparing rental prices based on furnishing status and area type.
- Exploring the influence of tenant preferences and property features on rental prices.
- Identifying the most expensive cities and rental locations.
- Visualizing rental trends and relationships using charts and graphs.

The goal is to extract meaningful insights into the rental market and understand the key factors associated with house rental prices.

## Insights

### Features

The dataset contains 12 features describing rental properties and their characteristics:

- **Property Information:** `BHK`, `Size`, `Bathroom`, `Floor`.
- **Rental Information:** `Rent`, `Posted On`.
- **Location Information:** `Area Locality`, `City`, `Area Type`.
- **Property Condition:** `Furnishing Status`.
- **Tenant Information:** `Tenant Preferred`.
- **Contact Information:** `Point of Contact`.

### Target

`Rent` — Continuous numerical variable representing the rental price of a property.

The objective is to predict house rental prices based on property characteristics, location, and furnishing status.
