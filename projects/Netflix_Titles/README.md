# Netflix Titles Data Analysis

## Problem

### Description

Streaming platforms offer a wide variety of movies and TV shows across different genres, countries, and release years. Analyzing this content helps understand the platform's catalog, identify content distribution patterns, and explore how Netflix's library has evolved over time.

The objective is to explore Netflix's movies and TV shows and investigate trends related to content type, release year, country, genre, ratings, and duration.

### Solution

Perform Exploratory Data Analysis (EDA) using the Netflix Titles dataset to investigate content distribution and uncover patterns across the platform's catalog.

The solution involves:

- Data cleaning and preprocessing.
- Handling missing values and inconsistent records.
- Exploratory data analysis and statistical analysis.
- Comparing the distribution of Movies and TV Shows.
- Analyzing content releases over the years.
- Exploring content distribution across countries.
- Investigating popular genres and categories.
- Analyzing content ratings and audience classifications.
- Comparing movie durations and TV show seasons.
- Identifying trends in Netflix's content library.
- Visualizing content distributions and trends using charts and graphs.

The goal is to extract meaningful insights into Netflix's content catalog and understand its distribution across different categories, countries, and time periods.

## Insights

### Features

The dataset contains 12 features describing Netflix titles:

- **Identification:** `show_id`, `title`.
- **Content Information:** `type`, `listed_in`, `description`.
- **Production Information:** `director`, `cast`, `country`.
- **Release Information:** `date_added`, `release_year`.
- **Content Classification:** `rating`.
- **Duration:** `duration` (movie runtime or number of TV show seasons).

### Target

No target variable — this project focuses on Exploratory Data Analysis (EDA) and statistical insights rather than supervised Machine Learning prediction.
