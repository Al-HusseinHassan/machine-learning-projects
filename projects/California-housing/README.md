# California Housing

## Problem

### Description

Housing prices vary across California depending on factors such as location, population, income levels, and housing characteristics.

The objective is to analyze the factors influencing housing values and predict median house values based on available geographical and demographic information.

### Solution

Develop a Machine Learning Regression model to predict median house values.

The solution involves:

- Data preprocessing and exploratory data analysis.
- Feature engineering and selection.
- Training and comparing regression models.
- Evaluating performance using MAE, MSE, RMSE, and R².

The goal is to estimate housing values and identify the factors that influence property prices.
