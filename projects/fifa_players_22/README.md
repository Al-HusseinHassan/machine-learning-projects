# FIFA Players 22 Data Analysis

## Problem

### Description

Football player performance and market value are influenced by various factors, including technical abilities, physical attributes, experience, and playing positions. Analyzing player data helps identify performance patterns, compare players, and understand the characteristics associated with highly rated footballers.

The objective is to explore FIFA 22 player attributes, evaluate differences between players and positions, and identify the factors that distinguish high-performing players.

### Solution

Perform Exploratory Data Analysis (EDA) using the FIFA Players 22 dataset to investigate player characteristics, performance ratings, and market values.

The solution involves:

- Data cleaning and preprocessing.
- Exploratory data analysis and statistical analysis.
- Analyzing player ratings and overall performance.
- Comparing player attributes across different positions.
- Investigating relationships between technical, physical, and mental attributes.
- Exploring player market values, wages, and potential ratings.
- Identifying top-rated players and valuable player profiles.
- Visualizing player distributions and performance patterns using charts and graphs.

The goal is to extract meaningful insights into football player performance and understand the factors associated with player ratings, potential, and market value.

## Insights

### Features

The FIFA 22 dataset contains player information and attributes, which can be grouped into the following categories:

- **Player Information:** `sofifa_id`, `short_name`, `long_name`, `age`, `nationality_name`.
- **Club Information:** `club_name`, `league_name`, `club_position`.
- **Player Ratings:** `overall`, `potential`, `value_eur`, `wage_eur`.
- **Physical Attributes:** `height_cm`, `weight_kg`, `preferred_foot`.
- **Position Information:** `player_positions`, `work_rate`.
- **Technical Attributes:** `pace`, `shooting`, `passing`, `dribbling`, `defending`, `physic`.
- **Detailed Skills:** `skill_moves`, `weak_foot`, and individual attacking, defensive, and goalkeeping attributes.

### Target

No target variable — this project focuses on Exploratory Data Analysis (EDA) and statistical insights rather than supervised Machine Learning prediction.
